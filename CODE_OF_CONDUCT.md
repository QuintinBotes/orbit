# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part in the project, in issues, pull
requests, reviews and any other project space, is expected to follow it.

## In short

- Be respectful and constructive, especially when you disagree.
- Assume good faith, and critique work rather than people.
- No harassment, insults, personal attacks, or unwelcome attention of any kind.
- Do not publish anyone's private information without their explicit consent.

## Reporting

Report unacceptable behaviour privately. Open the repository's **Security** tab,
choose **Report a vulnerability**, and start the title with "Conduct:" so it is
handled as a conduct report rather than a security issue. You can also use
GitHub's **Report content** option on the comment, issue or pull request
itself. Reports are reviewed promptly and kept confidential.

## Enforcement

The maintainer may remove, edit or reject comments, commits, code, issues and
other contributions that do not follow this code of conduct, and may
temporarily or permanently ban anyone whose behaviour is inappropriate,
threatening, offensive or harmful, following the enforcement guidelines of the
Contributor Covenant.
