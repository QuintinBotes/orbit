section: Changes
- **Changelog and traceability fragments (#230).** A pull request writes one file per entry under `changes/changelog/` and `changes/traceability/` instead of editing `CHANGELOG.md` and `docs/traceability.md`, so parallel pull requests stop conflicting on them. `node scripts/fragments.mjs check` (run by CI on pull requests) names a malformed fragment and a direct edit of a shared file; `node scripts/fragments.mjs fold X.Y.Z` folds them at release. `plugin/dist` is rebuilt once after each merge into `next` by `.github/workflows/rebuild-dist.yml`, and CI checks it on pushes to `next` instead of on pull requests.
