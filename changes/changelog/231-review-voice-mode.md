- **Review Voice as the same-family review pass (#231).** `review.mode: review-voice` replaces the fresh same-family session of a risky change with Review Voice's CLI, run by the controller on the exact candidate diff outside any worker, with `review.review_voice.command`. Its findings are validated, numbered `RV-n` and recorded with their anchors (blocking is high, important medium, minor low, nit and question info) and a blocking one goes to repair. The cross-model pass is unchanged. A CLI that is not installed, not set up, or fails twice falls back to the default session with a `review.review-voice-fallback` decision, and `orbit doctor` checks it. `review.review_voice.timeout_s` (default 900) bounds each run. Off by default.
