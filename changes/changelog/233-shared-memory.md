section: Off by default
- **Shared memory store (#233).** Set `knowledge.shared_memory: { enabled: true, command: [memory] }` (with `lessons_in_prompts: true`) to share lessons with the memory plugin. A worker's advisory block then also carries up to three of its items, with their ids, inside the same fence and `max_advisory_tokens`; when a run ends, each lesson it left validated is proposed to memory with the run as evidence, and a recalled item whose failure the run repeated is reported wrong through memory's feedback call. Orbit never activates an item. If memory is unreachable the run goes on without it and records `learning.memory-unavailable`; `orbit doctor` checks the command. Orbit's own lesson store works the same either way, and without the key nothing changes.
