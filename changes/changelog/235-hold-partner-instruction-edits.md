section: Off by default
- **A partner's edit to an instruction file is held for review (#235).** Partner implementers stay off (`routing.implementers: [claude]`). When one is switched on, a change by a non-Claude implementer to an instruction file (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md` at any depth, `.claude/skills|agents|commands`, `.cursor/rules`, `.github/copilot-instructions.md`) that the goal's scope does not name by path (a catch-all does not) blocks the run with the file named, so no later session loads it. One the scope names is allowed, always gets an independent cross-model review pass (the run blocks if none is usable), and its diff comes first in the review packet, whole or the run blocks. Claude-only runs are unchanged.
