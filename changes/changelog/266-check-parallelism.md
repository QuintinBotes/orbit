section: Changes
- `verification.check_parallelism` (1 to 16, default 1) runs that many of a policy's checks at once, in verification and the PREFLIGHT baseline (fail-before probes stay serial). No check reads another's output, so a round of checks can take about as long as its slowest one; checks still share the machine and the checkout, so the default stays 1, a check that rewrites a tracked file voids the whole set's evidence, and `orbit doctor` notes a higher value (#266).
