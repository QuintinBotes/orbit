section: Fixes
- **A repair that rebuilds an out-of-scope file again blocks (#300).** When Orbit restored out-of-scope paths before a repair and the repair wrote any of those paths again, the run went on spending attempts, because each rebuild made a new tree and the same-tree rule never matched. The run now blocks after that second denial, naming the paths. While the attempt allowance has room, a person's resume allows another try; the block message and the #280 and size blocks now say so only when it is true.
